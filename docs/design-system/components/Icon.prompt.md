Boxscore's stroke icon set (the app's own inline SVGs), used for tabs, headers, chevrons and actions.

```jsx
<Icon name="points" size={19} />
<Icon name="chevron-left" size={17} />
```

- Inherits `currentColor`. Stroke 1.8 for nav glyphs, 2.2 for chevrons/close/send, 3.2 for check.
- Never substitute emoji or another icon library.
