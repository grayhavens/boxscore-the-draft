The Boxscore mark (two ink corner brackets around an orange rounded square) built live from CSS, with the launch-splash animation.

```jsx
<BrandMark />                {/* plays once */}
<BrandMark animate={false} word={false} scale={0.5} />
```

For a static logo prefer assets/logo-header.png or assets/icon-512.png. Never redraw the mark another way.
